# Western Classic Pronunciation Playbook (Grade-6 Passage)

This playbook stores high-value pronunciation coaching patterns that can be reused by AI at runtime.
Scope: the current Unit-6 winter vacation passage and similar school dialogue texts.

## Why this file exists

- Improve targeting: map recurring error patterns to proven coaching drills.
- Save latency and cost: reuse concise drill templates instead of re-generating from scratch.
- Keep feedback actionable: each entry includes a short drill and a vivid memory hook.

## Core principles from research

1. Intelligibility first, accent second.
2. Suprasegmentals (stress/rhythm/intonation) strongly affect listener understanding.
3. High-variability minimal-pair training improves transfer.
4. Explicit phonetic cues plus corrective feedback outperform practice-only routes.
5. Connected speech features (weak forms/linking) are required for natural fluency.

## Runtime usage policy

- Pick only 1-3 entries with strongest evidence from audio or alignment.
- Do not apply an entry if no matching evidence exists.
- Convert selected entries into short Chinese coaching lines (one drill and one memory hook each).
- Rotate wording to avoid repetitive templates across students.

## Passage-specific focus shortlist

- High priority words: weather, there, them, fine, vacation, lanterns, sausages, Harbin.
- High priority fluency targets: thought-group pausing, linked speech in "going to / see ice", weak forms in function words.
